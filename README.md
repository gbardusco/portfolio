# Portfólio — Gustavo Bardusco

Site: **https://gbardusco.dev**

Portfólio de Gustavo Bardusco (docente de TI e desenvolvedor full-stack) no formato de uma viagem no tempo inspirada em *Chrono Trigger*: cada seção é uma era e rolar a página faz a Epoch viajar entre elas.

- HTML, CSS e JavaScript puros, sem build.
- Toda a pixel art (cenários, Epoch, personagem) é gerada em código em `art.js`.
- SEO/GEO: metadados Open Graph, dados estruturados JSON-LD, `sitemap.xml`, `robots.txt` e `llms.txt`.

Projeto de fã, sem fins comerciais. *Chrono Trigger* é marca da Square Enix.
